# User Management App

Приложение для управления пользователями с админ-авторизацией.

## Возможности
- Авторизация под администратором
- Просмотр списка пользователей
- Добавление / редактирование / удаление пользователей

## Стек
- React 18
- TypeScript
- React Router v6
- Ant Design 5
- Styled Components
- TanStack Query 4
- Axios
- Day.js
- MockAPI.io (бэкенд)
- Feature-Sliced Design (архитектура)
